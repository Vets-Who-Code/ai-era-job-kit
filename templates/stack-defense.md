# Stack Defense Doc

"Every line on your resume is a potential interview question." For every skill on the resume, answer four questions out loud in about 90 seconds. Can't? Remove it, study until you can, or reframe it at the level you actually worked.

| Skill (as the resume names it) | Resume line it backs | 1. What is it? | 2. When would you use it? | 3. What are the tradeoffs? | 4. A common mistake? | Grade (Defended / Thin / Cut) |
|---|---|---|---|---|---|---|
| | | | | | | |

Grade key (same as `resume-rebuilder`):
- **Defended:** all four answered with something you did, in your own words.
- **Thin:** you know the definition but not the tradeoffs or the mistakes. Study, then rerun.
- **Cut:** you can't answer 1 and 2. Remove the skill or reframe the line.

Rerun the two weakest skills with `/mock-screen` or the `final-round-panel` agent.
